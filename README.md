# pipe-test-1

## Привітання

Скрипт `scripts/greet.sh` виводить привітання для переданого імені; без аргументу вітає «світ».

```sh
$ bash scripts/greet.sh Оля
Привіт, Оля!
$ bash scripts/greet.sh
Привіт, світ!
```

Тест: `bash tests/greet_test.sh` (код 0 — успіх, 1 — помилка).

## Привітання за часом доби

Опція `--hour N` (ціле число 0–23) обирає привітання за періодом доби. Межі періодів задано в `scripts/lib/daypart.sh`:

| Години | Період | Привітання |
|---|---|---|
| 5–11 | ранок | Доброго ранку, <ім'я>! |
| 12–17 | день | Доброго дня, <ім'я>! |
| 18–22 | вечір | Доброго вечора, <ім'я>! |
| 23–4 | ніч | Доброї ночі, <ім'я>! |

```sh
$ bash scripts/greet.sh --hour 8 Оля
Доброго ранку, Оля!
$ bash scripts/greet.sh Оля --hour 19
Доброго вечора, Оля!
$ bash scripts/greet.sh --hour 23
Доброї ночі, світ!
$ bash scripts/greet.sh --hour 24 Оля; echo "код $?"
Невалідна година: «24» (очікується ціле число 0–23)
код 2
```

Без `--hour` поведінка не змінюється. Якщо година невалідна (`-1`, `24`, `abc`) або значення не вказано, скрипт пише повідомлення в stderr і завершується з кодом 2.

Тести: `bash tests/daypart_test.sh` і `bash tests/greet_test.sh`.
